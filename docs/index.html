Como ler estes dados

Os dados vêm de cadastros feitos pelos próprios órgãos e têm limitações importantes.

1Fonte

API de Dados Abertos do Obrasgov.br, do Ministério da Gestão e da Inovação (licença ODbL). Os dados são atualizados automaticamente toda semana.

2Localização pouco confiável

A maioria dos projetos atribuídos a Teresina tem a mesma coordenada genérica, e muitos ficam em outras cidades do Piauí. O painel mostra só os que provavelmente ficam em Teresina, com base em uma heurística sobre o nome da obra. O mapa só mostra coordenadas precisas.

3Pagamentos e repasses

Nas obras, só uma parte dos projetos tem empenhos na API do Obrasgov: "sem dado" não significa que nada foi pago. Os repasses por convênio vêm do Portal da Transparência (valor liberado pela União) e consideram convênios com vigência a partir de 2015. Convênios com o Governo do Estado ficam de fora, porque valem para o Piauí todo. Obra e convênio só são ligados quando o número do convênio aparece no cadastro da obra.

4Alerta não é irregularidade

"Com alerta" = Paralisada, Inacabada ou "Em execução" com prazo vencido. Atrasos podem ter causas legítimas (licenciamento, decisão judicial, rescisão). Valor pago = pagamentos do exercício + restos a pagar pagos.
